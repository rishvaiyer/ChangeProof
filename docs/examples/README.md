# AsterVale Living example documents

These small synthetic documents are ready to upload into the Triage Composer.

- `astervale-ar-incident-srs.txt` is the main recording document. It drives the cross-domain accounts-receivable investigation.
- `astervale-customer-id-migration-srs.txt` frames the `varchar` to `bigint` contract change and the compatibility checks around it.
- `astervale-regional-returns-reconciliation-srs.txt` focuses on returns, refunds, fulfillment timing, and regional policy.

All three documents describe the same fictional company and are synthetic. They are examples for the demo, not production requirements.
